# Extension Icons

To complete the extension setup, you need to add PNG icon files in the following sizes:
- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

## Quick Icon Generation Options:

### Option 1: Online Icon Generator
1. Visit https://www.favicon-generator.org/ or similar service
2. Upload an image or create an icon (use a shield or lock emoji/image)
3. Generate and download all sizes
4. Rename them to match the names above and place in this directory

### Option 2: Use an existing icon
Create simple colored square icons as placeholders:
1. Use any image editor (GIMP, Photoshop, Paint.NET, etc.)
2. Create a new image with purple/blue gradient background (#667eea)
3. Add a white shield emoji or checkmark symbol
4. Export in the sizes listed above

### Option 3: Screenshot an emoji
1. Open an emoji picker and find the shield emoji (🛡️)
2. Take a screenshot and crop it
3. Resize to the required dimensions
4. Save in PNG format

## Temporary Solution
For testing purposes, you can temporarily use any PNG files renamed to these names.
The extension will work without icons, but Chrome will show a default placeholder.
