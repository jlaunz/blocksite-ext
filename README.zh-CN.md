# FocusGuard - 快速上手指南

## 📥 安装（3步）

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的**开发者模式**
3. 点击**加载已解压的扩展程序** → 选择 `blocksite-ext` 文件夹

完成！扩展图标会出现在工具栏中。

## 🚀 基本使用

### 屏蔽网站

**方法1 - 快速屏蔽：**
1. 访问想要屏蔽的网站
2. 点击 FocusGuard 扩展图标
3. 点击 "Block This Site"（屏蔽当前网站）

**方法2 - 手动添加：**
1. 点击扩展图标
2. 输入 URL 规则（如 `facebook.com`）
3. 选择规则类型（精确/通配符/关键词）
4. 点击 "Add"（添加）

### 规则类型示例

| 类型 | 规则 | 效果 |
|------|------|------|
| 精确匹配 | `facebook.com` | 只屏蔽 facebook.com |
| 通配符 | `*.facebook.com` | 屏蔽所有 Facebook 子域名 |
| 通配符 | `*reddit*/videos*` | 屏蔽 Reddit 视频页面 |
| 关键词 | `youtube` | 屏蔽包含 "youtube" 的所有网址 |

### 临时解除屏蔽

被屏蔽时：
1. 在屏蔽页面点击 "Temporarily Unblock"（临时解除屏蔽）
2. 完成挑战（数学题/打字/等待计时）
3. 获得 15 分钟的访问时间

## ⚙️ 设置

点击弹窗中的 ⚙️ 按钮，或右键扩展图标 → 选项

- **屏蔽模式**：警告页面 或 重定向
- **挑战类型**：数学题 / 打字 / 等待计时 / 混合模式
- **等待时长**：10-300 秒可调

## 🎯 屏蔽规则详解

### 精确域名（Exact Domain）
- 输入：`facebook.com`
- 屏蔽：只有 facebook.com
- 适用：精确屏蔽单个网站

### 通配符模式（Wildcard）
- 输入：`*.facebook.com`
- 屏蔽：所有 Facebook 子域名（m.facebook.com、www.facebook.com 等）
- 输入：`*facebook*`
- 屏蔽：URL 中包含 "facebook" 的所有网页
- 输入：`*youtube*/shorts*`
- 屏蔽：YouTube Shorts 短视频

### 关键词匹配（Keyword）
- 输入：`reddit`
- 屏蔽：URL 中包含 "reddit" 的所有页面
- 适用：快速屏蔽整个网站及其所有相关页面

## 🧩 挑战系统说明

### 数学题（Math Problem）
- 随机生成加减乘法题
- 例：`17 + 23 = ?`、`7 × 8 = ?`
- 答错会生成新题目

### 打字挑战（Typing Challenge）
- 必须一字不差地输入激励短语
- 例："I am in control of my focus and time."
- 区分大小写和标点符号

### 等待计时（Wait Timer）
- 强制等待指定时间（默认30秒）
- 圆形进度条显示倒计时
- 可在设置中调整 10-300 秒

### 混合模式（Mixed）
- 先完成数学题
- 再等待计时结束
- 最强阻力，适合最容易分心的网站

## 💡 使用技巧

- 从最容易分心的 3 个网站开始屏蔽
- 使用**混合模式**挑战获得最佳效果
- 用**通配符** (`*.domain.com`) 屏蔽所有子域名
- 定期查看统计数据了解分心模式
- 使用开关功能临时禁用某个网站（无需删除）
- 查看"活跃的临时解除屏蔽"管理当前豁免

## 🔧 常见问题

**Q: 网站没有被屏蔽？**
- 检查规则是否已启用（✓ 符号）
- 尝试使用通配符模式如 `*example.com*`
- 确认 URL 模式匹配正确

**Q: 如何完全删除一个规则？**
- 点击弹窗中规则旁的 × 按钮
- 或在设置页面点击 "Delete" 按钮

**Q: 临时解除屏蔽能持续多久？**
- 默认 15 分钟
- 可在设置页面查看剩余时间
- 可以手动撤销（Revoke）

**Q: 能导出屏蔽列表吗？**
- 当前版本暂不支持
- 所有数据存储在本地浏览器中
